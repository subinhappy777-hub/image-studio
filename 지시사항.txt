과제 3

짤·카드 스튜디오
계획시간 4~5h
이미지와 문구를 조합해 밈·카드·SNS 게시용 이미지를 만들고 파일로 내려받는 제작 도구입니다.

왜 이걸 하는가
다양한 이미지와 문구를 안전하게 다루고 미리보기·내려받기·사용자 템플릿을 실제 데이터로 일치시킵니다.

제출물
결과물 주소 — 무로그인 공개 편집기
소스 주소
짧은 확인 방법 4줄 — 위치 / 3단계 이내 행동 / 통과 모습 / 안 될 때 모습
AI와 나의 판단 3줄 — AI에게 맡긴 일 / 직접 판단한 일 / AI 제안을 따르지 않은 일(없으면 이유)
완주 체크리스트
PNG·JPEG 편집과 잘못된 파일 거부가 됩니다.
세 화면비의 미리보기와 파일이 일치합니다.
극단 입력 12건을 검사했습니다.
템플릿 생성·불러오기·수정·삭제가 유지됩니다.
JSON 복원·완성 이미지·공개 안전을 확인했습니다.
증거 보관 기준
제출에는 주소·소스·짧은 확인법·AI와 본인 판단만 남깁니다.

카드 1 — 편집과 미리보기
하는 일
이미지를 불러와 한글 문구의 위치·크기·색을 바꾸고 즉시 미리 봅니다.

완료 목표 PNG·JPEG와 잘못된 파일을 안전하게 처리하는 첫 편집 흐름을 만듭니다.

첫 행동
사용 권한을 확인하고 메타데이터를 제거한 합성 이미지를 준비합니다.
PNG·JPEG·지원하지 않는 파일을 각각 불러옵니다.
통과 기준
T03-C01 제출한 모든 URL(결과물·소스)은 계정 생성·로그인·인증·초대·비밀번호·OAuth·CAPTCHA 없이 새 시크릿 창에서 열린다.
T03-C03 이미지 편집 도구와 문구 편집 도구가 첫 화면에 보인다.
T03-C04 PNG 이미지를 불러올 수 있다.
T03-C05 JPEG 이미지를 불러올 수 있다.
T03-C06 문구 위치 변경이 미리보기에 즉시 반영된다.
T03-C07 문구 크기 변경이 미리보기에 즉시 반영된다.
T03-C08 문구 색 변경이 미리보기에 즉시 반영된다.
T03-C09 지원하지 않는 파일을 넣어도 기존 작업이 유지된다.
T03-C10 지원하지 않는 파일의 거부 이유가 표시된다.
막히는 지점과 확인 순서
이미지나 문구가 보이지 않습니다.
파일 읽기 완료 → 미리보기 크기 → 입력 변경 후 다시 그리기
