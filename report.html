2. 짧은 확인 방법 (4줄)

위치 — 편집기 접속 후 중앙 캔버스

행동 (3단계 이내) — ① 우측 "문구 입력"에 긴 문장 입력 → ② "문구 추가" 클릭 → ③ 화면비를 16:9로 변경

통과 모습 — 텍스트가 캔버스 밖으로 나가지 않고 자동 줄바꿈·축소되며, 화면비 변경 후에도 캔버스 안에 유지됨

안 될 때 모습 — 텍스트가 캔버스 좌우/하단으로 잘리거나, 화면비 변경 후 사라지거나 겹침

3. AI와 나의 판단 (3줄)

AI에게 맡긴 일 — 5개 파일(state.js, main.js, template.js, assets-library.js, file-validation.js)의 코드 분석·문제 진단·수정 코드 작성, 자동 배치/자동 축소 알고리즘 설계

직접 판단한 일 — 인수인계 문서 요구사항 우선순위 결정, Undo 기록 타이밍·중복 방지 정책, "사용자 수동 배치를 덮어쓰지 않는" 자동 배치 원칙 설정

AI 제안을 따르지 않은 일 — AI가 제안한 "reflowAllTexts에서 겹침 재배치(reposition) 기본 활성화"를 채택하지 않음. 화면비 변경 시 사용자가 수동 배치한 텍스트를 강제 재배치하면 편집 의도가 훼손되므로 shrink(축소)만 기본 적용

5. 검사 10개 + 공통 사용 상한 (고정)

#검사 항목통과 기준공통 상한
1짧은 문장 추가캔버스 안에 표시, 기존 텍스트와 겹침 없음1회 시도
2긴 문장 자동 줄바꿈캔버스 좌우 밖으로 나가지 않음1회 시도
3긴 단어 자동 분할단어가 캔버스 밖으로 나가지 않음1회 시도
4사용자 입력 줄바꿈 유지Enter로 입력한 줄바꿈 위치 그대로 표시1회 시도
5글자 크기 120 + 긴 문장자동 축소되어 캔버스 안에 들어옴1회 시도
6화면비 16:9 → 1:1 변경텍스트 재배치/축소, 캔버스 안 유지1회 시도
7텍스트 실제 영역 클릭 선택글자 영역 클릭 시 해당 텍스트 선택3회 클릭 이내
8배경색·이미지크기·프레임 변경 후 Undo각 설정이 이전 값으로 복원각 1회
9스티커 회전 후 Undo + 회전된 스티커 클릭회전 전 상태 복원, 클릭 시 정확히 선택각 1회
10템플릿 저장 → 불러오기 (분할 레이아웃 포함)레이아웃·사진·텍스트 모두 복원1회

공통 사용 상한: 각 검사당 최대 3회 조작 이내 통과, 실패 시 1회 재시도 허용.
