## 2. AI A가 진행한 작업

AI A는 다음 기능을 개선했습니다.

1. 텍스트 자동 줄바꿈 및 실제 글자 영역 측정
2. 사용자가 직접 입력한 줄바꿈 유지
3. 긴 단어 및 긴 문장의 자동 줄바꿈
4. 텍스트 중앙 정렬 및 글자 영역 계산
5. 실제 텍스트 영역 기준 선택 기능
6. 텍스트 및 이미지 편집 Undo 개선
7. 스티커 회전 Undo 개선
8. 커스텀 스티커 삭제 버튼과 선택 버튼 구조 분리
9. 사진 분할 레이아웃 및 이미지 추가 Undo 개선
10. 배경색, 이미지 크기, 프레임 설정 Undo 개선

**주요 파일**: `state.js`, `main.js`

> 관련 기능이 여러 파일에 걸쳐 있으므로 수정 전 최신 코드를 먼저 확인해야 합니다.

## 3. 인계 시점 화면 상태 (2026-11-05)

- 편집기 정상 실행
- 이미지 불러오기 가능
- 텍스트 입력 및 추가 가능
- 여러 줄 텍스트 표시 가능
- 이미지와 텍스트가 캔버스에 표시됨

**추가 검증 필요 사항**

| # | 문제 | 확인 필요 내용 |
|---|---|---|
| 1 | 긴 문장 자동 줄바꿈 | 글자가 실제로 잘리는지, 텍스트 영역 계산과 렌더링 위치가 일치하지 않는지 |
| 2 | 텍스트 겹침 | 기본 배치 위치 문제인지, 사용자 이동 전 기본 동작인지 |
| 3 | 텍스트 위치 및 선택 | 실제 글자 영역 클릭 시 정확히 선택되는지 |

> 스크린샷만으로 기능 오류가 확정된 것은 아니며, 개별 테스트 결과를 기록해야 합니다.

## 4. AI B의 주요 작업

### 작업 A. 텍스트 자동 배치 기능 검증
- 테스트: 짧은 문장 / 긴 문장 / 긴 단어 / 직접 입력 줄바꿈 / 여러 줄 / 한글·영문 혼합 / 큰 글자 크기 / 캔버스 비율 변경
- 기준: 캔버스 밖으로 잘리지 않음, 적절한 자동 줄바꿈, 사용자 줄바꿈 유지, 실제 글자 영역과 선택 영역 일치, 글자 크기 변경 후 레이아웃 정상

### 작업 B. 텍스트 편집 기능 검증
- 테스트: 내용·크기·색상·글꼴 변경, 굵게, 이동, 삭제, Undo
- 기준: 각 편집 후 Undo 시 변경 전 상태로 복원

### 작업 C. 스티커 기능 검증
- 테스트: 추가 / 선택 / 이동 / 회전 / 커스텀 삭제 / Undo
- 기준: 회전 전 상태 복원, 삭제 버튼과 선택 기능 충돌 없음

### 작업 D. 이미지 설정 기능 검증
- 테스트: 배경색 / 이미지 크기 / 프레임 변경 / Undo
- 기준: 변경 전 값으로 정확히 복원

### 작업 E. 사진 분할 기능 검증
- 테스트: 1칸 / 2칸 / 4칸 레이아웃, 각 칸 이미지 추가·변경, Undo
- 기준: 레이아웃 변경과 사진 추가가 Undo 기록에 정상 반영

## 5. 인수인계 7항목 (코드 수정 시 주의사항)

AI B가 **새 환경에서 재현해야 하는 7개 항목**입니다.

| # | 항목 | 요구사항 |
|---|---|---|
| 1 | 기존 코드 충분히 확인 후 수정 | 수정 전 `main.js`, `state.js` 및 관련 파일 전체 확인 |
| 2 | 정상 기능 불필요 재작성 금지 | 이미 작동하는 기능은 재작성하지 않음 |
| 3 | `state.js` ↔ `main.js` 일치 | 텍스트 레이아웃 계산과 실제 렌더링·이벤트 연결이 일치 |
| 4 | Undo는 변경 전 상태 기록 | 변경 후 상태가 아니라 변경 전 상태를 저장 |
| 5 | 입력 실패로 Undo 누수 방지 | 입력 실패·이미지 로딩 실패만으로 Undo 기록이 쌓이지 않도록 |
| 6 | Undo 중복 생성 금지 | 하나의 편집 작업에 Undo 기록이 중복 생성되지 않도록 |
| 7 | Undo 시 UI·캔버스 함께 복원 | Undo 실행 시 관련 UI와 캔버스 상태도 함께 복원 |

**특히 `pointerdown`, `keydown`, `change`, `blur` 이벤트가 중복으로 기록을 생성하는지 확인해야 합니다.**

## 10. AI B 작업 완료 기록 (2026-11-05)

### 10-1. 수정한 파일

| 파일 | 주요 수정 |
|---|---|
| `state.js` | `AUTO_LAYOUT` 상수 추가, `measureTextLayout` maxWidth 동적 계산, bounds 대칭 계산, `fitTextToCanvas` / `findFreeTextPosition` / `reflowAllTexts` 신규, `drawTexts`가 `lineMetrics` 사용 |
| `main.js` | 자동 배치 호출, 텍스트/폰트 자동 축소, `bgColor`·`imageScale`·`frameType` Undo 추가, `bindUndoStart` keydown→input, `pickSticker` 회전 반영, 드래그 clamp, `aspectRatio` 스냅샷 포함, 템플릿 이벤트 수신, 텍스트 드래그 Undo |
| `template.js` | `splitLayout`/`splitImages` 저장·복원, `imageToData` PNG 보존, `importFromJson` 즉시 적용, `reflowAllTexts` 호출 |
| `file-validation.js` | `handleFile(file, onBeforeApply)` 콜백 추가, 성공 시에만 `remember()`, `reflowAllTexts` 호출 |
| `assets-library.js` | `createSpeechBubbleSticker` 캔버스 크기 설정 후 `ctx.font` 재지정 |
| `index.html` | 미연결 `inlineTextInput` / `splitUploadArea` 제거, `slotFileInput` 위치 정리 |
