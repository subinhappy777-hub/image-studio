# 🎨 짤·카드 스튜디오 (Image Studio)

사진과 다양한 편집 요소를 활용해 나만의 이미지와 카드를 제작할 수 있는 웹 기반 이미지 편집 프로그램입니다.

별도의 이미지 편집 프로그램을 설치하지 않아도 웹 브라우저에서 사진을 불러오고, 문구와 스티커를 추가하여 원하는 디자인을 만들 수 있습니다.

## 📌 1. 프로젝트 소개

**프로젝트명:** 짤·카드 스튜디오 (Image Studio)

**개발 목적**

사용자가 사진과 텍스트, 스티커, 그림 효과 등을 자유롭게 조합하여 자신만의 이미지 콘텐츠를 제작할 수 있도록 하는 웹 편집 프로그램입니다.

복잡한 편집 프로그램 대신 직관적인 화면 구성과 간단한 조작을 통해 누구나 쉽게 이미지를 꾸밀 수 있도록 구현했습니다.

## ✨ 2. 주요 기능

### ① 이미지 편집
- 이미지 파일 업로드
- 이미지 크기 및 위치 조절
- 캔버스 배경색 변경
- 1:1, 4:5, 16:9 화면 비율 지원
- 화면 확대 및 축소
- 사진 2분할 및 4분할 업로드

### ② 텍스트 편집
- 원하는 문구 추가 및 수정
- 글자 크기와 색상 변경
- 글꼴 변경
- 굵게(Bold) 설정
- 캔버스 내 텍스트 위치 이동

### ③ 스티커 편집
- 기본 이모지 스티커 제공
- 동물 귀 및 수염 스티커 제공
- 유행어 말풍선 스티커 제공
- 사용자 이미지로 커스텀 스티커 추가
- 스티커 크기 조절 및 회전
- 스티커 위치 이동 및 삭제

### ④ 그림 및 디자인 효과
- 자유로운 그림 그리기
- 형광펜 효과
- 네온 효과
- 글리터 효과
- 하트, 반짝이, 레이스, 폴라로이드, Y2K 프레임 제공

### ⑤ 저장 및 편집 관리
- 편집 결과 PNG 이미지 다운로드
- 템플릿 저장 및 불러오기
- JSON 파일로 편집 데이터 내보내기 및 불러오기
- 실행 취소 기능
- 사용자 추가 스티커 및 폰트 관리

## 🛠️ 3. 개발 환경 및 기술

| 구분 | 사용 기술 |
|---|---|
| 구조 | HTML5 |
| 디자인 | CSS3 |
| 기능 구현 | JavaScript |
| 이미지 편집 | HTML Canvas API |
| 데이터 저장 및 관리 | JSON, LocalStorage |
| 개발 도구 | Visual Studio Code |
| 소스 코드 관리 | Git, GitHub |
| 배포 | GitHub Pages |

### 주요 파일 설명

| 파일 | 역할 |
|---|---|
| index.html | 웹페이지 화면 및 편집 도구 구성 |
| style.css | 화면 디자인 및 레이아웃 |
| main.js | 버튼 이벤트와 편집 기능 제어 |
| state.js | 편집 상태 관리 및 캔버스 렌더링 |
| assets-library.js | 사용자 스티커 및 폰트 관리 |
| file-validation.js | 이미지 파일 검증 및 업로드 처리 |
| sticker-assets.js | 기본 스티커 데이터 관리 |
| template.js | 템플릿 저장 및 JSON 입출력 |

## 🚀 4. 실행 방법

### 방법 1. GitHub Pages에서 실행

아래 주소에 접속하면 웹 브라우저에서 프로그램을 사용할 수 있습니다.

- **서비스 주소:** https://subinhappy777-hub.github.io/image-studio/

### 방법 2. Visual Studio Code에서 실행

1. GitHub 저장소에서 프로젝트를 내려받습니다.
2. Visual Studio Code에서 프로젝트 폴더를 엽니다.
3. `index.html` 파일을 실행합니다.
4. Live Server 확장 프로그램을 이용하면 로컬 웹 서버에서 확인할 수 있습니다.

## 🖥️ 5. 사용 방법

1. **이미지 업로드:** 편집할 사진을 불러옵니다.
2. **화면 설정:** 원하는 화면 비율과 배경색을 선택합니다.
3. **텍스트 추가:** 문구를 입력하고 글꼴, 크기, 색상을 조정합니다.
4. **스티커 추가:** 원하는 스티커를 선택한 뒤 캔버스를 클릭합니다.
5. **디자인 꾸미기:** 그림 효과와 프레임을 적용합니다.
6. **결과물 저장:** PNG 다운로드 버튼을 눌러 완성된 이미지를 저장합니다.

## 🎯 6. 프로젝트를 통해 배운 점

이번 프로젝트를 통해 HTML, CSS, JavaScript를 활용한 웹 애플리케이션 개발 과정을 경험했습니다.

특히 다음과 같은 부분을 학습하고 적용했습니다.

- HTML Canvas를 활용한 이미지 및 편집 요소 렌더링
- JavaScript 모듈을 통한 기능별 코드 분리
- 이벤트 리스너를 활용한 사용자 입력 처리
- 편집 상태와 실행 취소 기록 관리
- 이미지 파일 검증 및 사용자 파일 처리
- GitHub를 활용한 소스 코드 관리와 웹 배포

기능을 구현하는 과정에서 발생한 오류를 확인하고, 데이터 구조와 렌더링 방식을 점검하면서 기능 간 연결의 중요성을 배울 수 있었습니다.
